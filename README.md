# Employment Effects of Canadian Minimum Wage Increases, 2023–2025

## Overview

This project examines the employment effects of recent minimum wage increases across Canadian provinces and industries using provincial panel data.

## Methodology

- Difference-in-Differences
- Dynamic Difference-in-Differences
- Event Study
- Robustness Checks
- Wild Cluster Bootstrap

## Key Findings

Recent minimum wage increases do not appear to have generated broad-based employment losses. Employment effects vary across industries and between the short and medium run, with statistically significant negative effects concentrated in a limited number of industries.
